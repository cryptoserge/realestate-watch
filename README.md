# 汐路の住まいウォッチ

[地図付きレポートを開く](https://cryptoserge.github.io/realestate-watch/)

SUUMOの公開情報から、汐路小学校区の売買物件を確認した時点の一覧です。
土地・戸建て・70㎡以上のマンションを対象とし、住所や面積の未確定部分を明記しています。
ピンは町丁目の代表点です。正確な物件位置や学区境界ではありません。

毎日18:00日本時間にクロアが調査します。調査ごとのレポートを保持します。
HOME’S・アットホームは取得制限のため対象に含みません。
掲載を確認できなくなっても成約とは判断しません。

Google Mapsの接続は公開時に設定します。接続キーはGitに含めません。
位置データ: [Geolonia 住所データ](https://github.com/geolonia/japanese-addresses)（旧版）。
